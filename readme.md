> Ya me he confundido varias veces con los archivos, asi que lo documentaré aquí:

- **Index.js** --> *Es un archivo hecho para realizar pruebas de código.*

`¿Para que sirve?`

*Es básicamente el código de **app.js**, pero usado para probar cosas y que no rompan el código principal.*


`Función principal:`  *Archivo de prueba*


- **App.js** --> *Archivo principal que gestiona todo.*

`¿Para que sirve?`

*Proceso principal de la aplicación, sin el, no hay nada*


`Función principal:`  *Proceso principal*


- **Launcher.js** --> *Es un **"Index.js"** antiguo, ya no se usa y está obsoleto*

`¿Para que sirve?`

*Es una copia de **Index.js** usada en las primeras versiones de desarrolado. Actualmente obsoleta remplazada por **"Index.js"***


`Función principal:`  *Archivo obsoleto*

- **Versions.json** --> *Archivo usado para verificar las versiones, está obsoleto porque no logré hacer que funcionará*

`¿Para que sirve?`

*Es un archivo que contiene todas las versiones, está desactualizado, ya no se usa y es candidato a eliminación*


`Función principal:`  *Archivo obsoleto*

- **index.html** --> *Archivo que se usará en el futuro*

`¿Para que sirve?`

*Se usará en el futuro para hacer la UI de la aplicación, probablemente con Electron*


`Función principal:`  *Archivo no usado actualmente*
